# Calculadora Divertida de Cálculo

## Descripción

Esta calculadora es un marco divertido para realizar operaciones de derivación y integración de funciones matemáticas. Su propósito es facilitar la comprensión de estos conceptos complejos a través de una interfaz intuitiva y visual.

### Características Principales

- **Derivación e Integración**: Calcula la derivada y la integral de una función de una o varias variables.
- **Pasos Detallados**: Muestra los pasos intermedios de cada cálculo, proporcionando una comprensión clara de cómo se obtiene el resultado.
- **Gráficos Interactivos**: Visualiza el comportamiento de la función original y el resultado de la operación seleccionada.
- **Guía Visual**: Ofrece una guía paso a paso para aprender de manera interactiva los cálculos matemáticos.

## Uso

1. **Escribir la Función**: Introduce la función matemática que deseas calcular en el campo de entrada. Puedes usar un teclado o los botones rápidos proporcionados.

2. **Seleccionar la Operación**: Escoje si deseas derivar o integrar la función. Elige el orden de derivación o integración si es necesario.

3. **Ver el Resultado**: Una vez que has ingresado la función y seleccionado la operación, haz clic en el botón "Calcular Ahora!" para ver el resultado y los pasos detallados.

4. **Interactuar con el Gráfico**: El gráfico interactivo mostrará la evolución de la función original y el resultado de la operación seleccionada.

5. **Guía Visual**: Para aprender de manera interactiva, haz clic en el botón flotante en la esquina superior derecha para ver la guía paso a paso.

## Funciones

### Calculadora de Derivadas y Integración

- **Derivación**: Calcula la derivada de una función de una o varias variables. Puedes derivar varias veces consecutivamente.
- **Integral**: Calcula la integral de una función de una o varias variables. Puedes integrar varias veces consecutivamente.

### Operaciones

- **Derivar**: Calcula la derivada de una función.
- **Integrar**: Calcula la integral de una función.

### Pasos Detallados
